# 木偶记忆·注入设计史（2026-11-21）

> 这份记「为什么这么设计、哪一版改的」，不记规则。规则册只收**丹阳批准 + 长期要守**的事；
> 设计取舍放这里（dsh-library），代码里放同名注释，提交说明里放同一句话。

## 一、总量问题：注入块会累积

**症状**：会话跑到 129 轮，上下文面板显示「注入内容 ≈396.8k tokens，占 72%」。
用户消息只有 1.8k。

**原因**：每次注入都是一条**独立消息追加**到历史，不是替换。每轮 400–3000 字 × 129 轮，
堆到近 40 万 token。模型每轮都要把前面所有注入块重读一遍。

**改法**（`dbe8cd3` / `151fc1f`）：每次注入前，把历史里**上几轮的 `<puppet_*>` 消息摘掉**，
只留最新一份。

- 判据严格：整条消息以 `<puppet_` 开头、首尾标签配对，才当注入块；正常发言不误删。
- 第一版只认 `content` 是数组的消息，宿主若存字符串就一条都摘不到、还不报错
  （`151fc1f` 兼容 字符串 / 数组 / `msg.text` 三种形态）。
- 每次注入留一行扫描回执：`注入去重扫描：历史 N 条，其中注入块 M 条`。
  「没摘」和「摘了 0 条」必须分得开——静默失败最难查。

## 二、首轮只给三张卡

**改法**（`b8620be`）：`cardsOnly = (plan.turn === 1)`，首轮把其它块（人设摘要、关系、笔记日记、
书签命中、顺手取回、交接纸条、熟人名片、到期、回忆提示、三线状态、现在时间）清空，
只留核心 / 规则 / 状态三张卡。

**依据**：实测首轮 2960 字 → 407 字；其中 `lore=735` 是被工具目录里的 `token`/`release` 拽出来的
（`6ca6333` 修掉），`handoff=176` 是一次性纸条（`5a3f40b` 改成注入即消费）。

**没动的东西**：三卡的强注入判定（首轮、每 100 轮、卡内容改过、压缩后）原样保留；
首轮被清的是「同一轮里额外塞的块」，不是卡。

## 三、三线状态（工作/陪伴/学习）

**来源**：从外部 agent 记忆产品的设计搬来的，不是自研。

**问题**：它说的「当前取向」和状态卡重复；注入正文还带一串「最近信号：…」的明细，
每轮都在变、对决策没帮助，纯占字数。

**处理**：
- `68fba2b`：删掉信号明细，只留取向 + 说话方式（首次轮 190 → 109 字）。
- `bce0a09`：**默认不再注入**，要注入必须显式 `lines.inject = true`；
  数据照常计算，要看用 `memory_state`。

## 四、人设：数字是显眼点，不是说明书

- 设计本意：**首轮 + 每 25 轮各给一个数字**（如 `96/100`），当作一眼能看到的标记。
- 中途走歪：加上了「完整度」这个词、一句解释「这只反映人设卡是否完整，跟演得好不好无关」、
  以及「先读一次 memory_core action=get target=core」的指路（`9ed9b29` 之前的版本）。
  这三样都是模型自己加的，不是设计。
- 收敛（`9ed9b29` → `b2b33fe`）：**只输出数字**，首轮与每 N 轮各一次；
  上下文真断了就直接补人设全文，不再发分数、不再发指路；断了又没卡就宁可不说话。
- 这个数字只是「注入字数 ÷ 应写字数」，**不是质量分**。

## 五、压缩后人设全文永远不触发（真 bug）

`68fba2b` 修。压缩事件把注入相位归零（`turn = 0`），下一轮 `phaseTurn = 1`；
而人设全文的判据写成 `phaseTurn >= 2`，于是**压缩后再也不触发**。
改成 `justCompressed || phaseTurn >= 2`，一次性标记 `personaDone` 继续防重复。

## 六、其它同期改动

- `6ca6333`：工具目录（`<available_tools>` 等）被当成用户说的话去检索，把「profile｜同步」这类
  无关记录拽出来；`stripInjected` 剥掉目录块后再检索。
- `0f7c8a8`：活日记 >200 字不收；没有小模型时把候选原文直接交给模型判，不再干等；
  去掉 `agreement-log` 巡检注入。
- `8026990`：记录冲突改为**追加历史**（变化也是记录），取回显示最新值并带「先前：旧值」。
- `b4e59cb`：记录册里**状态不算命中**，只做同分排序——状态里提一句「重启」不再拽出三条记录。
- `5a3f40b`：交接纸条注入即消费（标 `injected`），过期自动从盘上删。

## 七、当前生效形态（2026-11-21）

| 时点 | 注入什么 |
|---|---|
| 会话首轮 | 三张卡（全量）+ 人设数字 |
| 每 100 轮 | 三张卡（全量） |
| 卡内容改过 | 该卡当轮补 |
| 压缩后首轮 | 三张卡 + 人设全文（一次）+ 人设数字 |
| 压缩后第 2 轮 | 人设全文（一次，若首轮没轮到） |
| 平常轮 | 只注入命中的块；人设数字每 25 轮一次 |
| 三线状态 | **不注入**（数据保留） |

实测：首轮 407 字 / 3 块；常态底噪约 200 字（人设数字 + 现在时间）。
