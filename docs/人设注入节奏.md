# 人设注入节奏（2026-11-22 定稿 · 2026-11-22 二次修正）

## 结论

| 项目 | 取值 | 理由 |
|---|---|---|
| 数字锚 | **首轮 + 每 25 轮一次**（裸 `100/100`，不做加减） | 25 轮是「拉回出发的点」；**100 轮时与全量卡重合**，那一下是双重提醒（103 行全量 + 数字）。故意不在每轮给：每轮都有数字，就没有重点了 |
| 鼓励词（方向锚） | **每轮都给** | 它要在压缩后依旧有效——靠反复出现立住 |
| 两者关系 | 数字轮：`100/100` 换行鼓励词；其余轮：只有鼓励词 | 数字是刻度，鼓励词是方向 |
| 档位 | 只有 关 / 开，**默认开** | 旧的 off/score/roleplay 三档合并：有鼓励词就是「开」 |
| 全量卡 | 会话首轮 + 每 100 轮 | 自测里没有强注入跑到 400 轮人设仍有效 |
| 其余材料 | 首轮/100 轮或按需读本地文件 | 次要层，压缩掉不心疼 |
