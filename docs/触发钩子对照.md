# 触发钩子对照（每层各用各的，不合并）

> 2026-11-22 丹阳定：**触发方式大多数文件都不一样，是不同的钩子**。
> 这条是架构不变量——别再试图「统一成一套节奏」（统一试过，逐层回退）。
> 每层新增/改触发前，先看这张表，改哪层只动哪层的钩子。

| 层 / 文件 | 触发方式 | 落点 |
|---|---|---|
| 三张卡（core / rules / state） | 会话首轮 + 每 100 轮 + 内容改过当轮 + 压缩后首轮 | `cardInjectMode`（index.js） |
| persona.md（人设骨架） | 补充层节奏：**第 2 轮 + 压缩后**（整层不再每轮带上） | index.js 补充层规划 |
| 人设数字锚（100/100） | 首轮 + 每 25 轮，纯数字不做加减 | `persona-hint.js` |
| relations.jsonl | **主词命中**才给一行提示：只认 tags 带「称呼 / 身份」的条目，别名算代称；话题主词不触发 | `buildRelationCue` |
| notes.jsonl | 补充层（与 persona 同节奏，第 2 轮 + 压缩后） | index.js 补充层规划 |
| diary（按天） | 不整层注入：只在「按日期翻」的召回里出现；压缩后上下文就是它的浓缩 | `buildRecallInjection` 的 day 块 |
| saying（梗 / 口头禅） | 关键词命中 **且** 上下文缺失 >20% 才补，最多 2 条；过期的 `until` 不补 | index.js 常言块 |
| lorebook（约定书签） | 关键词命中 + 上下文缺失 >20% 才补 | `loreLayer().pick` |
| circle（圈子印象） | 他的话里提到哪个站点（链接 / 站名）就带那里的说话方式 | `circleLayer().pick` + `linkTriggersOf` |
| records（记录册） | 取词器按主词取（cueprompt 开启时）；冲突核对按「当前说法 vs 旧值」 | `cueprompt` / `buildConflictBlock` |
| memo（便签） / user（档案） | **不自动注入**，只能工具取（`memory_search` / `memory_pickup`） | — |
| array（会话索引） / deep（常言树 / 引导） | **不注入**，只供检索 | `memory_search` |
| due（到期） | 有到期项且未提醒过，提醒一次 | `buildDueInjection` |
| opening（按日期翻） | 他提日期 / 开场，且当天没翻过；**带 time（HH:mm）的行不走这里**，只报一句「N 条走计划任务」 | `buildOpeningInjection` |
| opening 带钟点（→ 宿主计划任务） | 抽出钟点即存 `time`；由每天 07:00 的「幕表排任务」任务扫表建一次性计划任务，到点投递 | `opening-autorecord.js` → `schedule_create` |
| **幕表·到点（插件兜底）** | 到点后的**第一轮**提一次：今天 + 带 `time` + 已过点 + 今天没提过；每条每天一次，隔天不补 | `buildTimedDueInjection`（挂 opening 同一入口） |
| **幕表·主动推送** | 60 秒轮询 + `agent.followup(消息)`：到点直接往会话插一条（会唤起一轮）；`opening.push=true` 才生效，开着时到点通道让位 | `pushTick`（index.js，照抄 dsh-schedule 的投递三行） |
| **幕表写侧（自动登记）** | **所有层**的写入（note/relation/user/memo/saying/diary/persona）与每轮活日记都过一遍：抽到「能解析的未来日期 + 具体事项」登记一行；主词/副词借记录册与关系层判断是谁的什么事；同天同主词同动作判重；假设句/问句/解析不出不记 | `opening-autorecord.js` + `autoRegisterOpening`（挂 `writeMemory` 总入口与 `queueNonWork`） |
| handoff（交接纸条） | 取走即消费，一次性 | `buildHandoffInjection` |

## 三条判据（防止又并成一套）

1. **知识类**（书签 / 常言 / 圈子）：关键词命中 + 上下文里没有才补——「已经有了就别重复」。
2. **关系类**（关系 / 熟人名片）：只有**人**才触发；话题名不算，人名和代称才算。
3. **节奏类**（三卡 / 人设 / 笔记）：按轮次或压缩事件，不掺关键词匹配。

## 改之前问自己

- 这层的触发源是什么？（关键词 / 人名 / 轮次 / 压缩事件 / 工具取）
- 改完会不会让别层跟着变？（并成一套＝回退的开始）
