## 内容

**对外只读接口（我们只做接口，不做桌宠）**（丹阳 2026-10-26：「我们只做接口」+「中午一块做」）。背景：市场里桌宠类插件不少（`whale-on-desk` 1435 下载、`dsh-live2d-avatar` 1250、`dsh-desk-pet` 957），但它们和记忆插件之间没有通道，装了也不会共享记忆。我们要做的是把记忆「露出去」，让别人接：①**只读汇总** `GET /dsh-puppet-memory-api/state` → 核心卡字数/预算、关系/日记/用户条数、最近的记忆事件、三线状态；②**只读检索** `GET /dsh-puppet-memory-api/search?q=&limit=3` → 要点 + hash（走 `briefOf` + `searchMemory`）；③**写入口默认关**：`POST /dsh-puppet-memory-api/event`，只允许写账本层（日记；「事件册」尚未实现，见 B-75——当时的措辞是顺手写的，2026-10-27 更正），绝不允许写 relations / user / core 卡，且必须在配置里显式打开。边界写进接口文档：只绑 `127.0.0.1`、不带凭据、不做远程；字段只增不改名，改名要写 changelog 且旧字段保留一个版本；不承诺任何第三方插件的兼容性。**不写桌宠说明书**（丹阳 2026-10-26：「桌宠的说明就不写了，用的少，况且最终的兼容也不是我们做的」）。已存在的 `/dsh-puppet-memory-api`（备份策略 API）说明挂路由这条路已通，照它加

## 验收

本地 `curl` 能拿到 state 与 search 的 JSON；默认配置下写入口返回 403/关闭态；打开后写一条事件，`memory_stats` 能看到日记涨 1；跨域/非 loopback 访问被拒；关掉配置后行为与现在完全一致
